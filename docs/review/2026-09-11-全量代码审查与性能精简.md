## 二、本轮新发现：功能性缺陷

### F-1（高）魔术工具「从源目录载入」按钮恒灰，功能不可达

[MagicToolsView.axaml:20](../../src/MediaOrganizer.Desktop/Views/MagicToolsView.axaml) 的按钮无 `CommandParameter`，而命令方法是 `[RelayCommand] private void LoadFromSourceDir(int max = 100)`（[MagicToolsViewModel.cs:85](../../src/MediaOrganizer.Desktop/ViewModels/MagicToolsViewModel.cs)）。

经 ICommand 调用时参数为 null。对照 CommunityToolkit.Mvvm 8.4 `RelayCommand<T>.CanExecute(object?)` 源码：`parameter is null && default(T) is not null → return false`——对非空值类型 `int` **恒返回 false，按钮永久禁用**。C# 默认值 `100` 永远不会经命令绑定生效。

**修法**：改为无参方法、方法体内写死 100（顺便删默认值误导）；或 XAML 加 `CommandParameter="100"`。

### F-2（低）SAF 请求码与通知权限码同值 0x1003

[AndroidStorageAccess.cs:14](../../src/MediaOrganizer.Android/Platforms/AndroidStorageAccess.cs) `RequestCode = 0x1003` 与 [MainActivity.cs:17](../../src/MediaOrganizer.Android/MainActivity.cs) `RequestCodes.PostNotifications = 0x1003` 同值。实际**无功能冲突**（权限结果走 `OnRequestPermissionsResult`，SAF 走 `OnActivityResult` + `_pending`），但同值易误读。并入 `RequestCodes` 取唯一值即可。
