# ADR-0001: 将照片整理程序从 Python 迁移到 C#

- 状态：已接受（Accepted）
- 日期：2026-08-08
- 决策者：用户 + WorkBuddy

## 背景

现有程序为 Python + PySide6 实现的照片/媒体整理工具（约 26 个源文件，GUI 单文件 92KB，魔术工具 76KB）。核心能力：多提取器加权投票提取拍摄日期 → 按日期分级目录 copy/move/link。用户希望迁移到 C#，并精简意义不大的功能。

## 决策

迁移到 C#：**Avalonia 12 + .NET 10 LTS**，Windows 优先、桌面跨平台顺带，Android 为远期愿景（故 Core/UI 严格分层）。项目定位**开源发布**，首发中文、文本外置预留英文。功能精简范围见 ADR-0002，技术架构见 ADR-0003。

## 候选精简清单（评审初判）

| 模块 | 体量 | 精简建议 | 理由 |
|------|------|----------|------|
| 多进程层（multiprocess_*） | ~44KB | **整体删除** | C# 用 `Parallel.ForEachAsync`/PLINQ 即可并行，无需进程池、临时 SQLite 日志合并、单进程回退等整套机制 |
| 魔术工具（magic_tools） | ~76KB | **大幅简化或删除** | 可视化正则生成器，体量最大；可降级为"正则 + 测试框"的简单编辑页 |
| 正则模式分析报告 | 小 | **删除** | 模式冲突/重复检测属于开发期工具，运行时价值低 |
| 详细模式（SQLite + MD5 去重） | ~15KB | **视需求裁剪** | 若不需要跨次去重，可只保留内存日志（simple 模式） |
| 内嵌视频播放器 | 中 | **删除** | 改为调用系统默认应用打开，省去多媒体控件依赖 |
| HEIC 支持 | 中 | **视需求裁剪** | Python 靠 pyheif；C# 生态（如 ImageMagick.NET / WIC）成本不同 |
| 多语言 | ~33KB | **视需求裁剪** | 个人自用可只保留中文 |
| 配置编辑器对话框 | ~37KB | **简化** | 只保留高频项，其余手改 JSON |
| 视频元数据写入（mutagen ©day） | 小 | **删除** | C# 无对等轻量库，收益低 |
| GUI 主题/窗口/预览尺寸配置 | 小 | **删除** | 写死合理默认值 |

## 必须保留的核心

1. 多提取器加权投票（EXIF → 文件名正则 → mtime 兜底）
2. 文件名正则模式体系（patterns.json 结构兼容）
3. 日期范围校验（max_years_past / future_date_buffer_days）
4. 年/月/日三级目录 + copy/move/link + skip/overwrite/rename
5. detail_config.json / unparsed_files.json 数据格式兼容
6. 失败文件的加载、单独修正（改日期/重命名）、批量移动
7. 分析报告（TXT）

## 后果

- 正面：摆脱 Python 打包/多进程/依赖碎片化问题；单解决方案结构清晰，Core 可测试可复用。
- 负面：魔术工具完整移植是最大工作量项；放弃与 Python 版数据格式兼容。
- 后续 ADR：ADR-0002（功能范围）、ADR-0003（技术架构）。
